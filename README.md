# 青提待办

一个轻量、护眼的响应式待办原型。当前版本为无需构建的单页 HTML，可直接在浏览器中打开。

## 功能

- 粘贴长段内容并拆分为待办条目
- 标记完成、划线保留和删除待办
- 每周完成情况可视化
- 拖动模块调整布局
- 导出未完成事项为 Apple 日历可导入的 `.ics` 文件
- 手机端紧凑布局

## 使用

直接打开 [`outputs/avocado-todo.html`](outputs/avocado-todo.html)。待办和模块顺序保存在当前浏览器的本地存储中。

## 当前限制

这是前端原型。Apple 日历采用手动导出/导入；网页提醒依赖浏览器权限，网页关闭时不会在后台触发。长文本拆分及日期识别目前由浏览器端的简单规则完成。
