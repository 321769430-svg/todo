# 青提待办

一个轻量、护眼的响应式待办应用。包含可直接打开的单页网页，以及 macOS 菜单栏应用。

## 功能

- 粘贴长段内容并拆分为待办条目
- 标记完成、划线保留和删除待办
- 每周完成情况可视化
- 拖动模块调整布局
- 导出未完成事项为 Apple 日历可导入的 `.ics` 文件
- 手机端紧凑布局
- macOS 顶部菜单栏常驻入口，点击🥑打开待办面板

## 使用

双击 `outputs/Qingti.app` 启动菜单栏版，点击屏幕右上方的🥑图标打开待办面板。

也可以直接打开 [`outputs/avocado-todo.html`](outputs/avocado-todo.html) 使用浏览器版。网页和菜单栏版分别使用各自浏览器的本地存储，内容不会自动互通。

## 重新构建 macOS 应用

在 macOS 13 或更新版本、安装 Xcode Command Line Tools 的 Mac 上运行：

```sh
./scripts/build-macos-app.sh
```

## 当前限制

Apple 日历采用手动导出/导入；网页提醒依赖浏览器权限，应用关闭时不会在后台触发。长文本拆分及日期识别目前由浏览器端的简单规则完成。应用数据只保存在本机 WebKit 存储中，尚未启用跨设备同步或登录时自动启动。
